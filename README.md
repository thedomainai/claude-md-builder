# Claude MD Builder

A CLI tool to generate optimized `CLAUDE.md` files for [Claude Code](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview) projects.

`CLAUDE.md` serves as the "constitution" for Claude Code, defining project identity, tech stack, commands, and boundaries. This tool helps you create comprehensive, structured, and token-efficient `CLAUDE.md` files automatically.

## Features

- 🔍 **Auto-detection**: Analyzes your project to detect languages, frameworks, and dependencies.
- 📝 **Templates**: Includes optimized templates for:
  - Web Frontend (React, Vue, Svelte)
  - Web Backend (Node, Python, Go)
  - Full Stack (Next.js, T3, SvelteKit)
  - CLI Tools
  - Libraries/Packages
  - Monorepos
- ✅ **Validation**: Checks your `CLAUDE.md` for missing sections, length, and security issues.

## Installation

```bash
# Install with pip
pip install claude-md-builder

# Or with uv
uv pip install claude-md-builder
```

## Usage

### Generate CLAUDE.md

Run the builder in your project root:

```bash
claude-builder generate
```

This will:
1. Analyze your project structure and `package.json`/`pyproject.toml`.
2. Suggest the best template.
3. Interactive ask for project details (Identity, Description).
4. Generate a `CLAUDE.md` file.

### Validate Existing CLAUDE.md

```bash
claude-builder validate
```

## Templates

The tool includes templates for various project types. You can also specify a template manually:

```bash
claude-builder generate --template fullstack
```

## Structure of CLAUDE.md

A standard `CLAUDE.md` generated by this tool includes:

- **Project Identity**: What is this project?
- **Tech Stack**: Languages, frameworks, key libraries.
- **Commands**: Build, test, lint, and run commands.
- **Structure**: Key directories and their purpose.
- **Principles**: Core architectural guidelines.
- **Boundaries**: "NEVER" and "ASK FIRST" rules.
